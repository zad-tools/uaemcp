# Support

## Public help

Use a GitHub issue for reproducible bugs, connector proposals and official data
source proposals. Search existing issues first and use the matching form so the
evidence and reproduction details are present from the start.

For deployment diagnostics, run:

```bash
bun src/index.ts doctor
```

Include the Bun version, UAEMCP version, transport (`stdio` or HTTP), operating
system and sanitized error output. Never include API keys, write tokens, cookies,
personal records or full production logs.

## Security and privacy

Do not open a public issue for a vulnerability, exposed credential, SSRF bypass
or unredacted personal data. Use GitHub private vulnerability reporting under
the repository Security tab, or email `vacrom414@gmail.com`.

## Official-data limitations

This community project does not represent the UAE Government and cannot answer
licensing, residency, tax, legal or eligibility questions on behalf of an
authority. Verify consequential decisions on the official source linked in each
result.
