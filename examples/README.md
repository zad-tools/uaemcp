# Examples

- `mcp-client.json`: remote Streamable HTTP client configuration.
- `rest-client.ts`: zero-dependency TypeScript SDK usage.
- `map.html`: standalone MapLibre vector-tile map.
- `../templates/connector-plugin.ts`: connector plugin starting point.
- `../templates/starter-bun-api/`: tiny Bun application consuming a UAEMCP instance.

All examples default to `http://127.0.0.1:8080`. Start the server with
`bun src/index.ts http`, then run an example.
